# Ziqi Li — portfolio

Static portfolio built with **Jekyll**, which GitHub Pages builds natively. Content is edited in **[Pages CMS](https://pagescms.org)** (forms configured in `.pages.yml`) or the GitHub web editor; every save republishes in ~1–2 minutes. No local tools or workflow file needed.

**Design v3 — “white page, crayon margins”:** pure white page, near-black ink, Instrument Serif (display) + Instrument Sans (text); colour only in hand-drawn crayon SVG doodles (muted yellow, coral, dusty blue, sage, lilac) in `_includes/art/` (generated by a script in the design workspace, not part of this repo). Every image slot uses `_includes/img.html`: the real image when a path is set, otherwise a grey wireframe box with an X. Pages are built from a front-matter `blocks` list (Pages CMS `type: block`, 12 layouts, rendered by `_includes/blocks.html`). Motion: GSAP + ScrollTrigger + Lenis loaded from jsDelivr only when the visitor allows motion (doodles draw on scroll, headline words rise, images unmask, gentle parallax); CSS + IntersectionObserver fallback. With `prefers-reduced-motion` everything is visible immediately and no motion library is downloaded.

👉 **Editing guide (中文优先 + English): [EDITING.md](EDITING.md)** — step-by-step Pages CMS guide, toy projects first.

## Structure
```
site.md                    name, links, SEO + all Home page content
about.md                   bio, portrait, CV
_beliefs/*.md              Home “How I work with kids” cards (one per belief)
_reflections/*.md          class & lab reflections, tagged by course (listed on the Lab Practicum page)
_sections/*.md             the 4 project areas (hub pages + blocks; findmy-voice.md holds its full case study)
_projects/<area>/*.md      sub-projects (case studies built from blocks), grouped by folder
images/<area>/<project>/   photos — every image in a project's folder shows in its gallery
images/home/kids-gallery/  Home photo gallery (auto)
index.html, projects.html  page shells (no content to edit)
_layouts/, _includes/, assets/   design template (HTML / CSS / JS); _includes/art/ = hand-drawn SVGs
.pages.yml                 Pages CMS forms (Chinese + English labels)
research/                  design research & progress images — excluded from the published site
sitemap.xml, robots.txt, 404.html
```

## Local preview (optional)
`bundle install && bundle exec jekyll serve` → http://localhost:4000 (tested with Jekyll 3.10, the version GitHub Pages uses).
